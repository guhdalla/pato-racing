# Imagens dos circuitos

Para cada circuito, adicione (opcionalmente) os arquivos:

```
public/images/circuitos/<id-do-circuito>/capa.jpg      # foto de capa (hero)
public/images/circuitos/<id-do-circuito>/tracado.png   # mapa do traçado
```

Extensões aceitas: `jpg`, `jpeg`, `png`, `webp`, `avif`.

Se os arquivos não existirem, o site mostra automaticamente um placeholder com a bandeira do país e o nome do circuito — não é necessário ter todas as imagens para o site funcionar.

Veja o `id` de cada circuito em `src/content/circuitos/circuitos.json`.
